## 数据说明

- 数据来自每日运行 `python run.py --date <日期> --codes <代码列表>` 后自动生成。
- 带 `*` 的字段由脚本生成，建议人工核验（机构预期利润、动态PE、PEG）；在 `manual/` 中做 override 后不再带星号。
- 无机构预期（机构未覆盖）的股票不进入报表。
- 「机构预期利润(亿)」为机构预测的全年净利润；「公告/研报链接」自动归集业绩预告/财报公告与研报 PDF 直链，点击可查看原文；「备注」列仅供人工填写。
- 点击左侧「每日报告」（`日期 财报跟踪`）可查看当天归档的原始 Markdown。
- 指标口径（动态PE、累计PE、同比/环比、PEG）见仓库 README。
